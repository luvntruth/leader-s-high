# v2 — 몰입형 캐릭터 대화 모드 (Immersive Character Mode)

> 상태: **기획 확정, 구현 보류(론칭 후 진행)**
> 작성: 2026-07-01
> 목적: 대화 시뮬레이션을 비주얼노벨/캐릭터챗 스타일(배경 + 풀바디 캐릭터 + 대화 오버레이)로 확장.

## 배경 / 동기
- 현재 시뮬레이션은 텍스트 중심 + 작은 원형 아바타 + 게임 HUD(신뢰 게이지·목표).
- 참고 레퍼런스(사용자 제공): 카페 배경 + 풀바디 캐릭터 + 대화 오버레이 + 컨텍스트 메뉴판.
- 기대 효과: 몰입감↑ → 리텐션·바이럴↑. 단 리더십 훈련(직장인 B2C) 톤 유지 필요.

## 톤 결정
- 후보 3종을 AI로 생성해 비교 (A 애니메 / B 세미리얼 / C 실사풍).
- **채택: B 세미리얼** (웹툰·모바일게임 일러스트 톤).
  - 이유: "진지하지만 부담 없는" 리더십 훈련 톤에 최적. 감정 표정 연출이 애니메만큼 유연하고 실사보다 자유로움. 20~30대 직장인에게 친숙.
  - 재검토 조건: 타겟이 시니어/임원급이면 C(실사), 엔터/젊은층 중심이면 A(애니메) 재고.

## 감정 소재 (검증 완료)
- 대표 캐릭터(한국 20대 후반 여성 직장인)로 감정 5단계 생성 — 얼굴·의상·배경 일관성 유지, 표정·자세만 변화 확인.
- 파일: `~/Downloads/letmefree-tone-test/감정세트-세미리얼/` (1_적대적 ~ 5_확신)
- 생성 방식: Gemini `gemini-3-pro-image-preview`(nano banana pro), 기준 이미지(B)를 입력 참조로 표정만 편집 → 캐릭터 일관성 확보.

### emotionStateMachine(7단계) → 이미지(5장) 매핑
| 감정 상태 | 이미지 |
|---|---|
| HOSTILE | 1_적대적 |
| DEFENSIVE / GUARDED | 2_방어적 |
| NEUTRAL | 3_중립 |
| OPENING / COOPERATIVE | 4_개방적 |
| CONVINCED | 5_확신 |

## 연동 구조
```
대화 → trustLevelService (신뢰 점수 0~100)
      → emotionStateMachine (7단계)
      → 감정 → 캐릭터 이미지 선택 → 크로스페이드 전환(200~300ms)
```

## 구현 시 필요한 것
1. **에셋 정식화**
   - 현재 소재는 배경 포함형 → 실제로는 **투명 배경 캐릭터 + 배경 분리** 권장
     (배경 고정, 감정별로 캐릭터만 교체 → 에셋 수·용량 절감)
   - 범위: 시나리오 대표 캐릭터부터 (예: 3~5명) × 감정 5단계
   - 캐릭터 일관성: 기준 이미지 1장 → 감정별 편집(입력 참조) 방식 유지
2. **몰입 모드 UI** (`screens/Simulation.tsx`에 토글 추가)
   - 레이어: `배경(fixed)` + `캐릭터 이미지(중앙, 감정 연동)` + `대화 오버레이(하단 반투명)` + `입력창`
   - 기존 게임 HUD(신뢰 게이지·목표)는 접기/오버레이 상단 축소
   - 모바일/데스크톱 반응형 (세로 9:16 캐릭터 기준)
3. **감정→이미지 매핑 테이블** + 프리로드 + 부드러운 전환
4. **성능**: 이미지 lazy/preload, WebP 변환, CDN

## 로드맵 (권장 순서)
1. **[선결]** 론칭 후 결제·리텐션 검증 (몰입 모드가 리텐션에 기여할지 판단 근거 확보)
2. 대표 캐릭터 1명 + 시나리오 1개로 **몰입 모드 프로토타입** (에셋 최소)
3. 사용자 반응/지표 확인 → 캐릭터·시나리오 확대
4. 에셋 파이프라인 정식화(투명 배경, 감정 세트 일괄 생성)

## 리스크 / 체크
- 톤 적합성(직장인이 캐릭터를 "가볍다"고 느끼지 않는지) — 소규모 테스트 필요
- 에셋 제작·유지 비용(캐릭터 × 감정 × 시나리오)
- 캐릭터 일관성(감정별 편집 시 얼굴 변형) 품질 관리
