# Ops Board MVP

## 목적
보스와 로키가 긴 채팅 없이도 현재 작업 상태를 한눈에 보고, 다음 행동과 막힘 여부를 빠르게 공유하기 위한 내부용 운영판.

## 포함 기능
- 5개 컬럼 보드: Inbox / This Week / In Progress / Blocked / Done
- 작업 카드 기본 정보
- 상세 패널
- localStorage 기반 상태 저장

## 접근 경로
- `/#/ops`

## MVP 한계
- 아직 카드 생성/수정 UI 없음
- 자동 채팅 연동 없음
- 멀티 에이전트 상태 연동 없음

## 다음 단계
1. 카드 생성/수정
2. 작업 로그 추가
3. assistant 자동 상태 업데이트
4. 결정 필요 카드 필터
5. 멀티 에이전트 진행 상태 연동
