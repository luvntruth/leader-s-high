## 4. 무료 티어 한도 분석

| 제한 | 한도 | 이 프로젝트 기준 | 초과 시점 |
|------|------|:--------------:|----------|
| 일 요청 수 | 500 RPD | 세션당 ~21회 | **일 23세션** 초과 시 |
| 분 요청 수 | 10 RPM | 동시 사용자 제한 | 동시 2명 이상 시 |
| 분 토큰 수 | 250,000 TPM | 세션당 ~41,000 | 동시 6세션 시 |

**결론**: 개인/소규모(일 23세션 미만)는 **완전 무료**, 그 이상은 유료 전환 필요.

## 5. 적용된 비용 최적화

| 최적화 | 내용 | 절감 효과 |
|--------|------|:---------:|
| 경량 프롬프트 (즉시 코칭) | 시스템 프롬프트 3,000→200 토큰, 입력 10→2 메시지 | 호출당 87% |
| 로컬 캐시 | 동일 메시지 재클릭 시 API 호출 0 | 중복 100% |
| 점수 간격 확대 | 3턴→4턴마다 신뢰도 점수 산출 | 호출 25% 감소 |
| GA 모델 통일 | gemini-2.5-flash 단일 모델 | 운영 복잡도 감소 |
| 수동 트리거 | 즉시 코칭/SOS는 버튼 클릭 시에만 호출 | 불필요 호출 0 |

## 6. 향후 추가 절감 옵션

| 옵션 | 예상 절감 | 난이도 | 설명 |
|------|:---------:|:------:|------|

| 멀티 프로바이더 (DeepSeek) | SOS/코칭 55% | 높 | 경량 작업만 저렴한 모델로 라우팅 |
| 배치 분석 | 코칭 호출 66% | 저 | 3턴 모아서 한 번에 분석 |
| 응답 스트리밍 조기 중단 | 출력 토큰 10~20% | 중 | 필요한 JSON 필드 완성 시 중단 |
