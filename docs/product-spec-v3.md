## 1. 제품 비전 한 줄 요약

> **"한국 팀장들이 팀원과의 어려운 대화를 AI와 먼저 연습하고, 실전에서 쓸 수 있는 전문가 코칭 플레이북을 받는 서비스"**

- 핵심 가치: **"말 한번 잘못하면 되돌릴 수 없는 1:1 면담"** 을 AI 로 **무한 리허설 + 전문가 코칭**
- 타겟: 신임·중간 팀장 (28-42세 / 관리자·리더 직무)
- 차별점: Gemini 기반 **5차원 신뢰도 스코어링 + 7단계 감정 머신 + SBI 피드백 모델**

## 2. 용어 정의 (중요 — 혼선 방지)

| 용어 | 정의 |
|------|------|
| **시뮬레이션** | 사용자(팀장)가 AI 팀원과 12턴 대화하는 훈련 세션 |
| **간략 리포트** | 1회 시뮬레이션 종료 직후 **무료로 보여주는 요약 피드백** (신뢰도 그래프 + 상위 2-3 포인트) |
| **풀 리포트 = 플레이북** | **동일한 개념**. 1회 시뮬레이션에 대한 **상세 코칭 자료** (아래 Section 6 구조). 유료. |
| **풀 리포트 단건 구매** | 게스트/무료 유저가 ₩3,900 로 **해당 시뮬레이션 1건에 한해** 플레이북을 구매하는 것 |
| **Pro/Ultra 플랜** | 해당 기간 내 **모든 신규 시뮬레이션의 플레이북을 자동 이용** 가능 |
| **FREE_SCENARIOS** | 무료 체험 고정 3개: `late-comer`, `boundaries`, `team-clash` |
| **중단** | 12턴 완주하지 않고 유저가 이탈한 시뮬레이션 |

## 4. 사용자 여정 스펙

### 4-A. 게스트(비로그인) → 플레이북 단건 구매

```
랜딩 (3 variants, ?lp=practice|diagnosis|new-manager)
  ↓ CTA 클릭 (utm_* 전달)
온보딩 (3개 무료 시나리오 제시)
  ↓ 시나리오 선택
Setup (캐릭터·상황 미리보기)
  ↓ "시뮬레이션 시작"
Simulation (12턴 대화, AI 응답, SOS/코칭 지원)
  ↓ 12턴 완주 (또는 HOSTILE 종료: trust≤5 && turn≥6)
Feedback (간략 리포트 무료 + 하단에 3개 CTA)
  │
  ├── ① [전문가 코칭 플레이북 ₩3,900 구매] → /signup (intent=golden-script)
  │    ↓ 회원가입/로그인 성공
  │   PurchasePlaybook (결제 화면)
  │    ↓ 결제 성공
  │   플레이북 뷰어 (풀 리포트 즉시 표시)
  │    ↓ [홈] or [마이페이지] 버튼
  │
  ├── ② [프로 플랜 구독하기] → /pricing → 로그인 유도 → PortOne 결제
  │
  └── ③ [다음 무료 시나리오 계속] → Setup
```

### 4-B. Pro 결제 후 시나리오 선택 (신규 플로우)

```
Pricing 에서 Pro 선택
  ↓ PortOne 결제
결제 성공
  ↓ /select-scenarios 자동 이동
시나리오 선택 화면 (Missions 팀원 보드 UI 재사용)
  · 40개 캐릭터 카드 표시
  · 사용자가 20개 클릭해서 선택
  · 선택한 개수 표시 (e.g., "12 / 20")
  ↓ [선택 완료 (20/20)] 버튼
profile.selected_scenarios JSONB 에 20개 ID 저장
  ↓
홈 이동 — 선택한 20개만 활성화된 상태
```

### 4-C. Ultra 결제 후

```
Pricing 에서 Ultra 선택
  ↓ PortOne 결제
결제 성공
  ↓ /profile?checkout=ultra 이동 (별도 선택 화면 없음)
40개 시나리오 자동 전체 활성화
```

### 4-D. 로그인 사용자의 시뮬레이션 → 플레이북

```
Home 또는 Missions 에서 시나리오 클릭
  ↓ (Pro/Ultra 는 자동 접근, Free 는 선택된 3개만)
Simulation → Feedback
  ↓ Pro/Ultra: 풀 리포트(플레이북) 자동 표시
  ↓ Free: 간략 리포트 + [플레이북 ₩3,900 구매] 버튼
```

## 5. 화면별 스펙 (사용자 기억 23개 항목 매핑)

### 5.1 Navigation (로그인 유저)

**4개 메뉴**: 기지 / 퀘스트 / 기록 / 프로필

| 메뉴 | 경로 | 설명 |
|------|------|-----|
| 기지 | `/` | 홈 대시보드. 추천 시나리오 카드 |
| 퀘스트 | `/missions` | 전체 시나리오 맵 (팀원 보드 UI) |
| 기록 | `/history` | 내 시뮬레이션 이력 리스트 |
| 프로필 | `/profile` | 마이페이지 (5개 서브메뉴) |

비로그인 유저에게는 Navigation **숨김** (메인 영역 풀폭 사용).

### 5.2 Home (`/` → 로그인 시 `/onboarding` 리다이렉트)

**무료 플랜**:
- 상단: 3개 무료 시나리오 카드 (FREE_SCENARIOS)
- 이미 완료한 시나리오: **카드 흐림 + "완료됨" 배지** + "다시 도전 불가 (무료는 1회)" 안내
- 하단: "20개 시나리오 더 필요하면?" → `/pricing` CTA

**Pro 플랜**:
- 상단: **사용자가 선택한 20개 시나리오** 중 미완료 우선 표시
- 진행률: "6/20 시나리오 시도"
- 기간 표시: "Pro 이용 중 · D-7"

**Ultra 플랜**:
- 40개 전체 카테고리별 그룹핑 표시

### 5.3 Missions (`/missions` — 퀘스트 보드)

**무료 플랜**:
- 40개 캐릭터 카드 표시
- 3개(FREE_SCENARIOS) 활성화, 나머지 37개는 **잠금 + "요금제 업그레이드" 라벨**
- 잠금 카드 클릭 → `/pricing` 이동

**Pro 플랜**:
- 선택한 20개 활성화, 나머지 20개 잠금 + "Ultra 업그레이드" 라벨

**Ultra 플랜**:
- 40개 모두 활성화

### 5.4 Feedback — 비로그인(게스트) 간략 리포트

화면 구성:
1. 신뢰도 변화 그래프
2. 요약 한 줄 ("귀하는 공감은 좋았으나 질문이 부족했습니다")
3. 핵심 강점 2-3
4. 핵심 개선점 2-3
5. **CTA 3개 (명시적 라벨)**:
   - 🎯 **[전문가 코칭 플레이북 ₩3,900 구매]** ← intent='golden-script' → /signup
   - 💎 [프로 플랜 구독하기] → /pricing

## 6. 풀 리포트 (플레이북) 구조 스펙

**Section 1: Summary & Score** (한눈에)
- 5차원 신뢰도 레이더 차트
- 종합 스코어 + 리더십 유형 판정 (Coaching / Directing / Delegating / Participating)

**Section 2: 3단계 대화 전략**
- Phase 1: 도입 (신뢰 구축)
- Phase 2: 본론 (핵심 메시지 전달)
- Phase 3: 마무리 (합의·다음 스텝)
- 각 Phase 별 사용자의 실제 발언 + AI 분석

**Section 3: 상황별 핵심 문장 (Golden Scripts)**
- 3-5개 결정적 순간 추출
- 사용자 실제 발언 vs 이상적 대안 발언
- 왜 이렇게 말하는 것이 좋은지 해설

**Section 4: 심리적 트리거 분석**
- 팀원의 반응을 바꾼 언어 패턴
- 놓친 기회 순간
- 방어심·개방성 전환 포인트

**Section 5: 전문가 코치 총평**
- 종합 피드백 (3-5문장)
- 이 사람의 강점 프로파일
- 다음에 반드시 연습해야 할 3가지

**Section 6: Action Items**
- 이번 주 실전 적용 과제 3개
